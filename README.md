# Personal Portfolio Website

A modern, professional portfolio website for web developers built with HTML5, CSS3, and vanilla JavaScript. This portfolio showcases your skills, projects, and accomplishments with an attractive, responsive design.

## 📁 Project Structure

portfolio/
├── index.html          # Home page with hero section and skills<br>
├── about.html          # About Me page with background, education, and experience<br>
├── projects.html       # Projects showcase with filtering capabilities<br>
├── styles.css          # Complete styling with responsive design<br>
├── script.js           # JavaScript for interactivity and functionality<br>
└── README.md          # Project documentation

## Feature Summary

-Modern, responsive portfolio layout with hero, about, projects, and contact sections.<br>
-Dark-themed styling with animated background and hover interactions.<br>
-Project filtering system for easy browsing by category.<br>
-Mobile-friendly navigation with hamburger menu.<br>
-Smooth entrance animations for cards and sections.<br>
-Contact form with validation feedback.<br>
-Clean, easy-to-customize HTML/CSS/JavaScript structure.<br>

## Usage Note
-Use this project as a starter portfolio to present your skillset and past work.<br>
-Replace placeholder text, project cards, and contact details with your own content.<br>
-Customize colors and images easily via styles.css and page HTML.<br>
